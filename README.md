- Hooks

## Development

Requires Node.js 24 and pnpm.

```sh
pnpm install
pnpm dev             # http://localhost:3000/terminal-portfolio
pnpm test            # unit tests + Storybook tests
pnpm storybook       # http://localhost:6006
pnpm lint
pnpm typecheck
pnpm build           # static site in out/
```
