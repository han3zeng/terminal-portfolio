# terminal-portfolio

This is my portfolio website in terminal style.

## Development principal

This is the repo, the milestone that I dive into learning how to integrate AI harness into software development process. I want to create and deploy this portfolio with most of work done by AI agents.

The key learning goals are following:

- TDD first
- SKILL
- Agents
- Hooks
- MCP
- CLAUDE.md

## Development

Requires Node.js 24 and pnpm.

```sh
pnpm install
pnpm dev             # http://localhost:3000/terminal-portfolio
pnpm test            # unit tests + Storybook tests
pnpm storybook       # http://localhost:6006
pnpm lint
pnpm typecheck
pnpm build           # static site in out/
```
